## Schedule
- **Day 1 (Launch Day):**
  - Verify `https://nilofarsdentaloasis.com/`, `/about`, `/treatments`, `/smile-gallery`, `/contact`, `/sitemap.xml`, `/robots.txt` all return `HTTP 200`.
  - Verify `https://www.nilofarsdentaloasis.com/` and old Odoo URLs (`/our-services`, `/about-us`, `/contactus`, `/community-services`, `/appointment`) return `301`.
  - Submit `https://nilofarsdentaloasis.com/sitemap.xml` in Google Search Console.
  - Update Google Business Profile website URL to `https://nilofarsdentaloasis.com/`.
- **Days 3–7:** Check GSC Indexing -> Pages for `404` or redirect errors; run Google Rich Results Test and PageSpeed Insights (`LCP <= 2.5s`, `INP <= 200ms`, `CLS <= 0.1`).
- **Days 14 & 30:** Compare GSC clicks, impressions, top local queries, and GBP calls/directions against the pre-migration baseline.
